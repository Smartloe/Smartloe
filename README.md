## 关于我 · About

写 Python 比较多，但不太甘心只写 Python。

我信一条很朴素的原则：**一件事重复三次以上，就该自动化掉。**
于是有了自动投简历的、自动发小红书的、自动签到的、自动分析弹幕的、自动生成封面图的……

结果是我花在维护这些自动化工具上的时间，比手动做那些事还多。

朋友说这叫「用战术上的勤奋掩盖战略上的懒惰」。
我说这叫热爱，谢谢。

理想是让机器替我干活，现实是我在给机器打工。
但至少——机器不会在周五下午六点提需求。

### Hi, I'm Chen Xirui — **Smartloe** on GitHub

I mostly write Python, but I refuse to write *only* Python.

I hold one simple belief: **if you do something more than three times, automate it.**
So I built things that apply to jobs for me, post to Xiaohongshu for me, check in for me,
analyse danmaku for me, generate cover images for me…

Which means I now spend more time maintaining those automation tools
than I ever spent doing those tasks by hand.

A friend calls this *"using tactical diligence to hide strategic laziness."*
I call it passion. Thank you.

```bash
$ whoami
Chen Xirui — but you can call me Smartloe
```
